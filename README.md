# Cybersikkerhetsportefølje

Jeg heter Daniel Alexander Kringen og går siste året på bachelor i cybersikkerhet ved Høyskolen Kristiania i Oslo. Her samler jeg studieprosjekter som viser hvordan jeg analyserer risiko, dokumenterer funn og begrunner sikkerhetstiltak.

| Emne | Faglig arbeid |
